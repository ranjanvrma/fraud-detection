# 💳 Fraud Detection — ML Model + API + Web App

End-to-end machine learning project that detects fraudulent online payment transactions using the **PaySim dataset**, served through a **FastAPI backend** and an interactive **Streamlit UI**, fully containerized with Docker.

**🔗 Live Demo:** [fraud-risk-simulator.streamlit.app](https://fraud-risk-simulator.streamlit.app/)

## Objective

Classify a transaction as genuine or fraudulent, prioritizing **recall** — in fraud detection, a missed fraud case is far more costly than a false alarm.

## Architecture

```
                 ┌────────────────────┐
                 │   train.py         │  reproducible training pipeline
                 │  (RF vs XGBoost)   │  → models/*.pkl + reports/*
                 └─────────┬──────────┘
                           │ loads
        ┌──────────────────┴────────────────────┐
        │                                       │
┌───────▼────────┐                    ┌─────────▼──────────┐
│  FastAPI (api/) │  /predict /health │  Streamlit (app.py)│
│  REST service   │                   │  Interactive UI    │
└───────┬─────────┘                   └─────────┬──────────┘
        │                                       │
        └─────── fraud_detection/features.py ───┘
              shared feature engineering (single source of truth)
```

Both services run in Docker via `docker-compose.yml`.

## Model

| Model | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| **Random Forest (selected)** | 0.992 | 0.995 | 0.994 | 0.999 |
| XGBoost | 0.984 | 0.998 | 0.991 | 0.998 |

*Full comparison, confusion matrix, and ROC curve: [`reports/`](reports/) — regenerated by `train.py`.*

**Features**: `step`, `type`, `amount`, `oldbalanceOrg`, `newbalanceOrig`, `oldbalanceDest`, `newbalanceDest`, plus engineered signals — `amount_to_balance_ratio`, `sender_drained`, `dest_was_zero`, `balance_error_orig`, `balance_error_dest` (see [`fraud_detection/features.py`](fraud_detection/features.py)).

## Project Structure

```
fraud_detection/     shared feature-engineering module (used by train, API, and app)
train.py             reproducible training + evaluation pipeline
api/                 FastAPI service (main.py, Dockerfile)
app.py               Streamlit UI (single-transaction + batch CSV scoring)
tests/               pytest unit + API tests
reports/             metrics.json, model_comparison.md, confusion matrix, ROC curve
notebook/            original EDA + model exploration notebook
models/              serialized model + column order
```

## Running Locally

```bash
pip install -r requirements.txt
```

**Streamlit app:**
```bash
streamlit run app.py
```

**FastAPI service:**
```bash
uvicorn api.main:app --reload
```
Docs at `http://localhost:8000/docs`.

**Retrain the model:**
```bash
python train.py
```

**Run tests:**
```bash
pytest
```

## Running with Docker

```bash
docker compose up --build
```

- Streamlit UI → `http://localhost:8501`
- FastAPI service → `http://localhost:8000`

## API Example

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"step": 2, "type": "TRANSFER", "amount": 9000, "sender_balance": 9500, "receiver_balance": 0}'
```

